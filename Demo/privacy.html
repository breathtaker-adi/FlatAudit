Architectural Privacy Guarantee

Privacy by Architecture,
Not by Policy.

Most privacy policies are promises made in English about servers located in the cloud. FlatAudit's privacy is enforced by computer code that runs entirely on your physical computer. We don't store your personal data because we never receive it.

🛡️ The Four Architectural Invariants

FlatAudit is engineered around four inviolable guarantees that hold true across every supported browser and portal:

1. Zero PII Collection

FlatAudit never asks for, records, stores, or transmits your name, phone number, email address, IP address, search queries, or UPI identifiers.

2. 100% In-Browser Execution

The entire heuristic audit engine—including the 5-level MAD price ladder, advance-fee regex scanner, and deposit multiple checks—runs inside the local Chrome tab in <300ms.

3. 100m Spatial Grid Anonymization

When fetching OpenStreetMap infrastructure, exact coordinates are mathematically rounded to a coarse 100m bounding grid. The public OSM server never receives your exact flat or building location.

4. Client-Side Photo Fingerprinting

64-bit dHash perceptual image fingerprints are calculated inside an offscreen canvas on your machine. Images are never uploaded to any remote server.

🔍 Chrome Extension Permissions Transparency

Under Apple Human Interface Guidelines and modern browser security standards, here is the full disclosure of every permission requested in manifest.json and why it is technically necessary:

Permission Technical Purpose Data Scope & Guarantee
storage Stores your personal watchlist, saved listings, and custom metric thresholds. Strictly stored in chrome.storage.local. Never synced to any remote database or cloud provider.
activeTab Allows content script execution to read listing DOM nodes when you visit a property page. Scoped exclusively to supported real estate portals (NoBroker, MagicBricks, 99acres, Housing.com). Passive on all other websites.
offscreen Downscales property images to 8×8 grayscale bitmaps for 64-bit dHash perceptual fingerprinting. Executes inside an isolated sandboxed background canvas. Bitmap data is destroyed immediately after hash generation.

🌐 Network Traffic & External APIs

FlatAudit communicates with external servers solely when explicitly requested by user action:

OpenStreetMap Overpass API: When you view the Area Report, FlatAudit issues a read-only query to the public OpenStreetMap Overpass API (overpass-api.de) to tally public amenities (metro stations, schools, hospitals, supermarkets). The request contains only quantized coordinates (rounded to 3 decimal places / ~100m) and receives only raw OSM node counts.

FlatAudit includes zero analytics trackers, zero tracking pixels, zero advertising SDKs, and zero telemetry beacons. No Google Analytics, no Mixpanel, no Facebook Pixel, no Sentry.
